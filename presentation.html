Engineering Approach

Production-Grade 4-Tier Cloud Architecture & Hybrid RAG

Tier 1: Client Layer

React 19, Vite 8, Tailwind CSS, TanStack Router, client-side caching, responsive mobile & dark/light theme.

Tier 2: API Gateway

FastAPI asynchronous services (<15ms latency), JWT auth, multipart PDF/DOCX extractors, Cloudinary CDN.

Tier 3: AI & Hybrid RAG

NVIDIA NIM / Llama 3 LLM client, Qdrant Vector Store (1024-dim dense embeddings) + Rank-BM25 Lexical Fusion.

Tier 4: Data Layer

Relational PostgreSQL/SQLite schemas mapping user profiles, past selection records, and daily job creation streams.

Technical Rigor & Guardrails

• Reciprocal Rank Fusion (RRF): Merges semantic vector similarity with keyword BM25 precision to guarantee factual scheme responses.

• Strict JSON Schema: Pydantic models enforce guaranteed extraction of ATS scores, skills, and roadmaps without format drops.

• Zero Cloud Compute Lock-in: Fully decoupled architecture ready for on-premise institutional or cloud deployment.

Engineered for high-throughput, sub-second latency, and explainable AI recommendations.
